# Text Mining and Linguistic Pattern Analyzer

I will build a menu-driven application to analyse text using dynamic storage and word-frequency records.

The application will count words, find the longest and most frequent words, sort and search word statistics, display memory addresses, and produce a summary with a custom analysis. It will use pointer traversal and function pointers.

## Files

- `src/main.c`: placeholder for the application code.
- `data/`: the selected published paragraph and its source details.
- `tests/`: tests for word statistics, punctuation, growing input, and memory handling.

Before implementation, I will select a published paragraph of at least 150 words and review the word-processing rules and custom analysis. Compile and run instructions will be added when the program is ready.
