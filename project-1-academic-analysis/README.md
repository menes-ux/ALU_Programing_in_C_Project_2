# Academic Performance and Risk Analysis

I will build a menu-driven application to manage student records and analyse their grades.

The application will support adding and removing students, displaying records, sorting, searching, grade calculations, a custom analysis, and a summary report. It will use dynamic memory, pointer traversal, and function pointers.

## Files

- `src/main.c`: placeholder for the application code.
- `tests/`: tests for record operations, calculations, invalid input, and memory handling.

Before implementation, I will review the initial dataset, pass threshold, and custom analysis. Compile and run instructions will be added when the program is ready.
