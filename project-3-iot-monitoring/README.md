# IoT Event Monitoring and Callback Engine

I will build a console application to manage simulated IoT devices and process their readings through callbacks.

The application will support temperature, pressure, and battery voltage devices. It will register and remove devices, simulate at least 10 readings, report alerts, and generate a monitoring summary. It will use structures, a union, dynamic memory, pointer traversal, and a custom callback.

## Files

- `src/main.c`: placeholder for the application code.
- `tests/`: tests for device operations, callback dispatch, alerts, and memory handling.

Before implementation, I will review the reading ranges, alert thresholds, and custom callback. Compile and run instructions will be added when the program is ready.
